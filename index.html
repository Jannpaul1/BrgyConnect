ABOUT THE PROJECT

One place for everyday barangay needs.

Barangay Connect is designed to make barangay services easier to access, more organized, and more convenient for residents.

🎯

Purpose

Give residents a faster and more convenient way to access services, request assistance, and manage appointments.

🚀

Objectives

  • Improve appointment scheduling
  • Organize resident information
  • Make requests easier to track
💡

Problem & Solution

Instead of relying only on manual processes, the system brings appointments, requests, records, and updates together in one interface.

KEY FEATURES

Everything connected in one system.
